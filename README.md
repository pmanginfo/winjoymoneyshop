## 윈조이머니상이란?

윈조이머니상은 윈조이 포커 등에서 사용되는 게임머니와 관련된 시세, 이용 방법, 거래 절차 등의 정보를 확인할 때 검색되는 용어입니다.

* 현재 게임머니 시세 안내 여부
* 판매·매입 절차가 명확한지 확인
* 거래 전 금액과 조건 확인
* 이용 가능한 게임 종류 확인
* 연락처와 상담 방법 확인
